# Policy

Declared constraints. Gates are evaluated by `resolve` and their verdicts
ride every resolution record; a failed or skipped gate annotates the record
and only admission refuses on it — records state facts, gates gate
promotion.

`parity.json` holds the tree-parity gates for the three Unreal plugin
dual copies: the standalone repository is the source of truth, the
HolobikeExperience-mounted copy must match it file for file, and the
excluded names (build output, generated trees, project-authored Content)
are declared per gate rather than assumed by the tool. The failure class
is not hypothetical — mounted copies have run ahead of their repositories
before; these gates make the drift a recorded fact on the day it happens.

The endpoint-literal gate the build-out plan anticipated has no sites to
declare: the 8765 hardware endpoint did not survive HolobikeCore's gateway
rework, and a gate for a dead literal would be coverage theater. The
literal-parity kind arrives with the first literal that actually spans
repositories.
